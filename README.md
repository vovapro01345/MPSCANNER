------------------------------------------------------------
ЧТО ЭТО
------------------------------------------------------------

MCscanner — статический веб-сайт для мониторинга Minecraft-
серверов, найденных внешним сканером (написан на Rust,
обходит диапазон IP и портов 1024–65535 за ~3 часа).

Особенность: API не используются как единственный источник
правды. Каждый сервер проверяется через несколько независимых
API, ответы сверяются между собой, вычисляется уверенность
(confidence) и медиана числовых полей.


------------------------------------------------------------
ВОЗМОЖНОСТИ
------------------------------------------------------------

СВОЙ ДВИЖОК СКАНИРОВАНИЯ
  • Параллельные пробы (primary + secondary)
  • Cross-verification с вычислением confidence
  • Медиана для игроков и max-игроков
  • Retry с экспоненциальным backoff
  • TTL-кэш результатов (5 минут)
  • Ручная очистка кэша

ДАННЫЕ СЕРВЕРОВ
  • Иконка, MOTD, версия, игроки
  • Точное определение онлайна через 2–3 API
  • Автоматическая проверка Bedrock-порта (19132)
  • Список игроков онлайн (если сервер отдаёт Query)
  • Uptime за последние 30 сканов + sparkline-график

ФИЛЬТРЫ И СОРТИРОВКИ
  • По статусу: онлайн / офлайн / избранные
  • По тегам: PvP, Anarchy, SkyBlock, Modded и т.д. (14 тегов)
  • По версии: 1.8 / 1.12 / 1.16 / 1.18 / 1.19 / 1.20 / 1.21
  • Слайдер по игрокам (min/max)
  • Фильтр "С высокой уверенностью" и "Спорные"
  • Сортировка: по уверенности, uptime, заполненности,
    игрокам, названию, версии

------------------------------------------------------------
ФОРМАТ servers.json
------------------------------------------------------------

Поддерживаются три формата — определяется автоматически.

ФОРМАТ 1 — простой массив (Rust-сканер)

[
  {
    "address": "147.185.221.16",
    "port": 11641,
    "online": true,
    "motd": "A Minecraft Server",
    "players_online": 0,
    "players_max": 20,
    "version": "1.21.10"
  }
]

ФОРМАТ 2 — с метаданными

{
  "_meta": {
    "scanner_version": "1.2",
    "scanned_at": "2026-10-13T14:23:00Z",
    "ip_range": "147.185.221.16-231",
    "ports_scanned": 64512,
    "found": 214
  },
  "servers": [ ... ]
}

ФОРМАТ 3 — альтернативные поля

[
  {
    "ip": "147.185.221.16",
    "port": 11641,
    "players": 0,
    "max_players": 20,
    "version": "1.21.10"
  }
]

Поля address/ip/host и players/players_online взаимозаменяемы.


------------------------------------------------------------
WORKFLOW
------------------------------------------------------------

  1. Rust-сканер (у тебя локально)
     • Обход диапазона IP
     • Перебор портов 1024-65535
     • 3 часа на полный цикл, раз в выходные
     |
     v
     servers.json

  2. Обновляешь файл в репо (или кидаешь drag-and-drop)
     |
     v

  3. MCscanner на GitHub Pages
     • Принимает servers.json
     • Проверяет каждый сервер через 2-3 API
     • Cross-verification + confidence
     • Показывает только реально работающие
     • Считает diff с прошлой загрузкой
     • Копится история
     |
     v

  4. Кнопка "Для сканера"
     • Экспорт только онлайн-серверов
     • Формат совместим с Rust-сканером
     • Можно скормить обратно


------------------------------------------------------------
КАК РАБОТАЕТ CROSS-VERIFICATION
------------------------------------------------------------

ОДИН СЕРВЕР — минимум 2 пробы, максимум 3

              scanServer()
                   |
        +----------+-----------+
        |                      |
        v                      v
  mcsrvstat.us           mcstatus.io
   (primary)             (secondary)
        |                      |
        +----------+-----------+
                   |
         Совпадают ли ответы?
               /        \
              Да         Нет
              |           |
              |           v
              |      mcapi.us
              |     (tiebreaker)
              |           |
              +-----+-----+
                    |
                    v
              crossVerify()
              • Голосование
              • Confidence %
              • Медиана значений
              • Флаги conflict/verified


ЧТО СЧИТАЕТСЯ

  online         Большинство голосов
  confidence     % проб, согласных с решением
  players        Медиана чисел от согласных проб
  maxPlayers     Медиана от согласных проб
  icon           Из первой пробы, которая её вернула
  version        Из первой пробы с непустой версией
  verified       >=2 успешных проб И >=2 согласных
  conflict       Есть пробы, противоречащие решению

------------------------------------------------------------
API-ПРОБЫ
------------------------------------------------------------

  mcsrvstat.us        primary     5 минут кэш
  mcstatus.io         secondary   без ключа
  mcapi.us            tiebreaker  1 запрос/мин
  mcsrvstat.us (bedrock) bedrock  5 минут кэш

Все API бесплатные и без ключей.


------------------------------------------------------------
НАСТРОЙКА
------------------------------------------------------------

В начале app.js:

  const SCANNER_CONFIG = {
      delayMs: 1500,           // пауза между серверами (мс)
      cacheTTL: 5 * 60 * 1000, // TTL кэша (5 минут)
      probeTimeoutMs: 12000,   // таймаут одной пробы
      retryMax: 1,             // retry при ошибке
      retryBackoffMs: [2000],  // пауза перед retry
      autoScanIntervalMs: 7 * 24 * 60 * 60 * 1000
  };

Если ловишь 429 (Too Many Requests):
подними delayMs до 2500 или 3000.


------------------------------------------------------------
ОГРАНИЧЕНИЯ
------------------------------------------------------------

  • Браузер не может подключаться к Minecraft-серверам
    (TCP + бинарный протокол). Все проверки идут через
    публичные API.

  • Пиратский / лицензионный сервер точно определить
    нельзя без эмуляции клиента. Эвристика основана на
    ключевых словах в MOTD.

  • mcsrvstat.us требует заголовок User-Agent, иначе
    возвращает 403.

  • mcapi.us — не более 1 запроса в минуту с клиента.

  • Гео (ipwho.is) не используется — удалено.
